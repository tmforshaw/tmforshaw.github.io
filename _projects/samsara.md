<p>
	An offhand item which I implemented the functionality of, in the game Samsara, which is developed in Unreal Engine 5.
	The item is called the Peacock Fan Mirror and it has the ability of projecting a shield infront of the player, which absorbs projectiles and converts the damage into charge, which is then used to create an AOE ability which heals allies and stuns enemies.
	I developed a custom material which creates a ripple on the surface of the shield where the latest projectile hit it.
	An ability can be created, using a portion of the built-up charge (Amrita area), in the direction that the player is facing.
</p>

<hr class="major" />

<h2>Energy Shield</h2>

<p>
	The shield is deployed in front of the player while they hold down the parry button, only if they are holding the offhand weapon in their hand (can't be used with two-handed weapons), and they have some focus<sup>1</sup> available.
	Any player movement also affects the shield since it is attached to them.
	The shield gains charge depending on the blocked projectiles' damage, and changes colour between blue (uncharged) and red (charged) to represent this.
	There are sounds for when the shield is raised and lowered, as well as when a projectile impacts it, and when it becomes fully charged.
</p>

<p>
	<sup>1</sup> Focus is a resource in the game which is generated by parrying, killing, and other player actions.
</p>

<hr class="minor" />

<h3>Shield Material</h3>

<p>
	There is a custom material which takes in an impact position and impact time which is passed to it when the shield hits a projectile.
	The <em>frequency</em>, <em>intensity</em>, <em>radius</em>, <em>colour</em>, and <em>lifetime</em> of the ripples are all customisable variables in the material.
	The ripples dissipate using an exponential falloff function.
</p>

<hr class="major" />

<h2>Amrita Area (AOE Ability)</h2>

<p>
	This is the cone-shaped ability which can be created when holding the Fan Mirror and tappning the parry button when charge is above a certain threshold.
	The amrita area is an effect that heals allies (and the player), while putting the enemies in a stunned state.
	The enemies which have been stunned are tracked in an array, so that they will only be stunned once.
	After a certain duration, the ability will dissipate itself.
	The area plays a looping sound while active, and a sound upon destruction.
</p>

<hr class="major" />

<h2>Animations and Actions</h2>

<p>
	There are animations which happen for the shield being impacted, and the ability being used, they are made using Unreal Engine actions.
	For the ability animation, a custom action was created which lets the developer change the offset for spawning the cone, so that it can match each character's particular move.
	Sounds are also implemented at this stage so that the amrita area has a particular sound when created.
</p>

<hr class="major" />

<h2>Focus Depletion</h2>

<p>
	Using the shield consumes a customm resource from the player, called Focus Points, it is a drain over time rather than a single reduction in focus.
	The shield has a variable, <em>use_focus</em>, which enables the checks for focus, and the draining of it.
	If the player doesn't have the required focus, and <em>use_focus</em> is enabled, a dialog appears indicating that there is not enough focus.
</p>
